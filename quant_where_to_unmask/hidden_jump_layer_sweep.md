# Hidden jump при unmask: sweep по слоям

Traces: **64**, unmask-событий на слой: **4096**, checkpoint: `checkpoints/results_wikitext_fp16_g64_n256`, layers: **0..32** (33 hidden states incl. embed)

## Методология

Один forward на step → `output_hidden_states=True` → метрики jump/traj/control на **completion-регионе** (64 позиции) для каждого слоя.

- **layer 0** — embedding output
- **layer 1..31** — промежуточные блоки
- **layer 32** — last block (то, что раньше брали как `layer=-1`)
